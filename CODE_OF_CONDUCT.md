# Code of Conduct

## Our Commitment

Priyaraa is built around creativity, collaboration, and community.

We are committed to creating a welcoming, inclusive, and respectful environment for everyone participating in this project, regardless of experience level, background, identity, or perspective.

Whether you're opening your first issue, submitting a pull request, reviewing code, or contributing ideas, you're welcome here.

---

## Our Values

We believe in:

* Respectful collaboration
* Constructive feedback
* Learning and growth
* Inclusivity and accessibility
* Supporting creators and innovators
* Building together, not competing against each other

We encourage contributors to help maintain a positive environment where everyone feels comfortable sharing ideas and contributing.

---

## Expected Behavior

Examples of positive behavior include:

* Treating others with respect and professionalism
* Giving constructive feedback and suggestions
* Being open to different viewpoints and experiences
* Helping new contributors get started
* Giving credit where it is due
* Focusing on what benefits the project and community

---

## Unacceptable Behavior

The following behaviors are not tolerated:

* Harassment, discrimination, or hate speech
* Personal attacks, insults, or derogatory comments
* Trolling, intimidation, or intentionally disruptive behavior
* Publishing someone else's private information without permission
* Deliberately misleading contributors or maintainers
* Any conduct that creates an unsafe, hostile, or unwelcoming environment

---

## Maintainer Responsibilities

Project maintainers are responsible for clarifying and enforcing community standards.

Maintainers may remove, edit, or reject comments, commits, issues, pull requests, discussions, or other contributions that violate this Code of Conduct.

---

## Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct, please report it through:

* GitHub Issues (when appropriate)
* Repository Discussions
* Direct communication with project maintainers

All reports will be reviewed fairly and handled respectfully.

---

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub Issues
* Pull Requests
* Discussions
* Documentation
* Community interactions related to Priyaraa

---

## A Final Note

Good code matters.

Good communities matter more.

Let's build both.
